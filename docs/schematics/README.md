# Schematic samples

This directory stores schematic files used for Belfegor documentation, parser development, and build/validation experiments.

| File | Description |
| --- | --- |
| `camp.litematic` | Small campsite/base reference schematic used while validating Litematica import behavior. |
| `zephiowl_large_survival_house.litematic` | External simple-house style test schematic used to exercise larger imported blueprint parsing. |

Runtime schematic imports should copy user-selected files into the Minecraft/Belfegor working folders before construction starts. These repo copies are fixtures and examples, not the user's active world schematics.
